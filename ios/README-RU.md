# Проект ANBridge для iPhone

Откройте `ANBridge.xcodeproj` в Xcode. Настройте свою Team в Signing & Capabilities и выполните Product → Run на подключённом iPhone.

Исходники переносимого ядра находятся в `Sources/ANBridgeCore`, XCTest — в `Tests/ANBridgeCoreTests`, исполняемые проверки — в `Sources/ANBridgeCoreCheck`.

Подробные инструкции и команды проверки находятся в [основном README](../README.md).
